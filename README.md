# Netflix-Dashboard-Analysis
Project Title: Netflix Dashboard Analysis using Power BI

Project Description:
This project is a Netflix Data Analysis Dashboard developed using Power BI to analyze Netflix movies and TV shows data. The dashboard provides meaningful insights into the total number of shows, ratings, genres, directors, release years, and country-wise distribution of Netflix content.

The dashboard contains KPI cards showing important information such as Total Shows (8803), Total Ratings (19), Genre Shows (515), Total Directors (4527), Start Date (1925), and End Date (2021). Different visualizations like bar charts, donut charts, maps, and line charts are used to represent data in an easy-to-understand way.

The project also analyzes:

* Rating by Total Shows to identify the most common content ratings.
* Genres by Total Shows to understand popular genres.
* Movies and TV Shows distribution using a donut chart.
* Country-wise content analysis through a world map.
* Release year trends to observe how Netflix content has grown over time.

Tools Used:

* Power BI
* DAX Functions
* Data Visualization Techniques

DAX Functions Used:
COUNT(), COUNTROWS(), DISTINCTCOUNT(), MIN(), MAX(), CALCULATE()

Objective:
The main objective of this project is to analyze Netflix content and create an interactive dashboard that helps users understand trends, ratings, genres, and content growth effectively.
